AI 직원 회사

회사 하나가 폴더 하나입니다. 직원은 마크다운 카드 한 장이고, 주고받은 일은 사람이 열어 읽는 파일로 남습니다.

다운로드 모든 릴리스

왜 로컬 우선인가

기억이 남의 서버가 아니라
내 폴더에 쌓입니다

직원이 일한 기록은 벡터DB 안에 갇히지 않습니다. 일지도 노트도 산출물도 전부 내 디스크의 마크다운 파일이라, Coai를 지운 뒤에도 그대로 열립니다.

회사 하나 = 폴더 하나

직원 카드, 대화, 일지, 산출물이 한 폴더 아래 모입니다. 통째로 복사하면 그게 백업입니다.

기억이 저절로 엮입니다

닮은 노트끼리 양방향으로 이어지고, 무엇이 무엇과 붙어 있는지 별자리로 보여 줍니다.

권한은 파일이 아니라 상수

직원이 만질 수 있는 범위는 코드에 얼어 있습니다. 설정 파일을 고쳐 스스로 권한을 올릴 수 없습니다.

엔진은 고르는 것

Anthropic 구독이나 API 키, 사내 vLLM 주소를 회사마다 따로 넣습니다. 한 곳에 묶이지 않습니다.

다운로드

두 가지 형태로 씁니다.

Windows 10/11 · x64

Coai 데스크톱

v0.1.2 · 설치본(.exe) · 약 105MB

설치본 받기
  1. 1실행. 내려받은 설치본을 두 번 누릅니다.
  2. 2경고 넘기기. SmartScreen이 막으면 추가 정보 다음 실행을 누릅니다. 아래를 함께 읽어 주세요.
  3. 3엔진 넣기. 설정 화면에서 쓰실 엔진 자격을 넣으면 직원이 일을 시작합니다.

SHA-256
bbf9aa8d6e929dc4504eba13e28ced7fda88814b08d4a625ce9e7c6309d842cf

Linux 셀프호스트 · x86-64

Coai 서버

v0.1.2 · tar.gz · 약 151MB · Node 동봉(glibc x86-64)

타르볼 받기 
# 풀고 안내를 읽습니다
tar -xzf coai-server-0.1.2-linux-x64.tar.gz
cd coai-server && cat README.md

# Node가 안에 들어 있어 따로 안 깔아도 됩니다
./node server.js

동봉된 Node는 glibc용입니다. Alpine 같은 musl 배포판에서는 시스템 Node 20+ 로 node server.js 를 쓰세요.

SHA-256
cb13ad54679cb4d4c29954ab32282e35646f969c082dc335dd1bd028d71421d6

먼저 알아 두실 것

숨기지 않고 적습니다

서명이 없습니다
Authenticode 코드 서명을 하지 않았습니다. 그래서 Windows가 만든 사람을 확인해 주지 않고 SmartScreen이 막습니다. 이 저장소의 릴리스에서 받은 파일만 쓰시고, 위의 SHA-256과 대조해 주세요. PowerShell에서 Get-FileHash .\Coai_0.1.2_x64-setup.exe -Algorithm SHA256.
엔진은 따로입니다
Coai는 모델을 갖고 있지 않습니다. 설치한 뒤 쓰실 엔진의 자격을 넣어야 직원이 움직입니다.
업데이트는 묻고 설치합니다
v0.1.1부터 앱이 새 버전을 확인해 알려 주고, 누르시면 설치합니다. 몰래 받아 깔지 않습니다. v0.1.0을 쓰고 계시면 이번 한 번은 위에서 받아 직접 설치해 주세요 — v0.1.0에는 업데이트 기능 자체가 없습니다.
